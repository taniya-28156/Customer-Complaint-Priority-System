# 🤖 AI Customer Complaint Priority System

## 📌 Project Overview

The AI Customer Complaint Priority System is an end-to-end Machine Learning application that automatically analyzes customer complaints, predicts the complaint category, assigns a priority level, and generates an intelligent customer support response.

The project is built using Machine Learning, Natural Language Processing (NLP), FastAPI, and Streamlit.

---

## 🚀 Features

- Complaint Category Prediction
- Complaint Priority Prediction
- Intelligent AI Analysis
- Automated Customer Reply Generation
- Complaint History Tracking
- Interactive Dashboard
- FastAPI Backend
- Streamlit Frontend

---

## ▶️ How to Run

### Install dependencies

```bash
pip install -r requirements.txt
```

### Start FastAPI

```bash
uvicorn main:app --reload
```

### Start Streamlit

```bash
streamlit run app.py
```
